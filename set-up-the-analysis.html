15.2 Define the geographical domain and reference sites

The analysis is conducted across Sub-Saharan Africa. The shapefile ssa.shp defines the geographical boundary used to crop and mask the spatial datasets.

The reference sites are provided as a GeoPackage. In this example, the layer contains the Living Lab polygons and a district attribute identifying each reference site.

ssa <- vect("Data/ssa.shp")

reference_sites <- vect("Data/ll_mfl.gpkg")

reference_sites <- reference_sites[reference_sites$district %in% c("Senegal", "Ethiopia",
    "Kenya1", "Kenya2", "Zimbabwe", "Ivory Coast"), ]

plot(ssa, main = "Sub-Saharan Africa")
plot(reference_sites, add = TRUE, col = "blue")

15.3 Load the spatial datasets

All spatial input datasets are called at the beginning of the workflow. This makes the data requirements explicit and allows users to check that all files are available before starting the processing steps.

Two cropland datasets are used in the workflow:

  • cropland.tif: cropland fraction or proportion, used to estimate cropland area;
  • cropmask.tif: binary cropland mask, used to define the pixels included in the analysis.

Check the values and units of these two rasters before proceeding. The cropland fraction should be expressed either as a proportion (0–1) or as a percentage (0–100). The binary mask should identify cropland pixels with a positive value and non-cropland pixels with NA or zero.

cropland_fraction <- rast("Data/cropland.tif")
cropmask <- rast("Data/cropmask.tif")

plot(cropland_fraction, main = "Cropland fraction")
plot(cropmask, main = "Cropland mask")

The soil indicators used in the analysis are:

  • sand content in the 0–30 cm soil layer;
  • total soil nitrogen at 30 cm;
  • available water content (AWC) from the Harmonized World Soil Database (HWSD).
sand <- rast("Data/sand_0_30cm.tiff")

sand = resample(sand, cropmask, method = "bilinear")

The indicators are measured in different units and have different ranges. They are therefore standardized using Z-scores before calculating Euclidean distances.

For each indicator \(k\), the standardized value is:

\[ z_{pk} = \frac{x_{pk} - \mu_k}{\sigma_k} \]

where \(x_{pk}\) is the value of indicator \(k\) in pixel \(p\), and \(\mu_k\) and \(\sigma_k\) are the mean and standard deviation of that indicator across the analysis domain.

indicator_means <- global(indicator_stack, "mean", na.rm = TRUE)
indicator_sds <- global(indicator_stack, "sd", na.rm = TRUE)

indicator_means <- as.numeric(indicator_means[, 1])
indicator_sds <- as.numeric(indicator_sds[, 1])

indicator_z <- (indicator_stack - indicator_means)/indicator_sds

names(indicator_z) <- paste0(names(indicator_stack), "_z")

plot(indicator_z)

Each reference site is characterized by the mean value of each standardized indicator within its polygon. The resulting site profile represents the environmental and socioeconomic conditions associated with that site.

The district attribute identifies the reference sites.

site_names <- unique(reference_sites$district)
site_names <- site_names[!is.na(site_names)]

site_profiles <- data.frame(site = site_names, matrix(NA_real_, nrow = length(site_names),
    ncol = nlyr(indicator_z)))

names(site_profiles)[-1] <- names(indicator_z)

for (i in seq_along(site_names)) {

    site_polygon <- reference_sites[reference_sites$district == site_names[i], ]

    site_values <- extract(indicator_z, site_polygon, fun = mean, na.rm = TRUE)

    site_profiles[i, -1] <- as.numeric(site_values[1, -1])
}

15.4 Calculate technology transferability

For each reference site, the Euclidean distance between the site’s mean standardized profile and every cropland pixel is calculated.

\[ d_{pi} = \sqrt{\sum_{k=1}^{K}(z_{pk}-\bar{z}_{ik})^2} \]

where:

  • \(d_{pi}\) is the distance between pixel \(p\) and reference site \(i\);
  • \(z_{pk}\) is the standardized value of indicator \(k\) in pixel \(p\);
  • \(\bar{z}_{ik}\) is the mean standardized value of indicator \(k\) at reference site \(i\);
  • \(K\) is the number of indicators.

Distance is converted into a transferability index using an exponential decay function:

\[ Pr_{pi} = \exp(-\lambda d_{pi}) \]

The parameter \(\lambda\) controls how rapidly transferability decreases as distance increases. A larger value produces a more restrictive transferability surface.

The value used in the original script is 0.4. This parameter should be treated as an analytical choice and tested through sensitivity analysis.

lambda <- 0.4

transferability_stack <- rast()

for (i in seq_along(site_names)) {

    site_profile <- as.numeric(site_profiles[i, -1])

    distance_squared <- (indicator_z - site_profile)^2

    distance_to_site <- sqrt(sum(distance_squared))

    transferability <- exp(-lambda * distance_to_site)

    names(transferability) <- site_names[i]

    transferability_stack <- c(transferability_stack, transferability)
}

15.5 Calculate cumulative reach

The cumulative reach analysis estimates the cropland area and rural population located in pixels with transferability values equal to or greater than a given threshold.

The physical area of each pixel is calculated in hectares. Cropland fraction is then used to estimate the cropland area within each pixel.

The following code accommodates cropland fractions expressed either as proportions or percentages.

maximum_cropland_fraction <- global(cropland_fraction, "max", na.rm = TRUE)[1, 1]

cropland_divisor <- ifelse(maximum_cropland_fraction > 1, 100, 1)

pixel_area_ha <- cellSize(cropmask, unit = "ha")

cropland_area_ha <- pixel_area_ha * (cropland_fraction/cropland_divisor)

cropland_area_ha <- mask(cropland_area_ha, cropmask)

The cumulative reach is calculated at thresholds from 1 to 0, in increments of 0.05. For each threshold, the cropland area and rural population in pixels meeting or exceeding the threshold are summed.

transferability_thresholds <- seq(1, 0, by = -0.05)

total_cropland_ha <- global(cropland_area_ha, "sum", na.rm = TRUE)[1, 1]

total_rural_population <- global(rural_population, "sum", na.rm = TRUE)[1, 1]

Calculate cumulative reach for each reference site

cumulative_reach <- data.frame()

for (i in seq_along(site_names)) {
    site_transferability <- transferability_stack[[i]]
    cumulative_cropland <- numeric(length(transferability_thresholds))
    cumulative_population <- numeric(length(transferability_thresholds))
    for (j in seq_along(transferability_thresholds)) {
        threshold_mask <- site_transferability >= transferability_thresholds[j]
        cumulative_cropland[j] <- global(cropland_area_ha * threshold_mask, "sum",
            na.rm = TRUE)[1, 1]
        cumulative_population[j] <- global(rural_population * threshold_mask, "sum",
            na.rm = TRUE)[1, 1]
    }

    site_reach <- data.frame(reference_site = site_names[i], transferability_threshold = transferability_thresholds,
        cumulative_cropland_ha = cumulative_cropland, share_cropland_pct = 100 *
            cumulative_cropland/total_cropland_ha, cumulative_rural_population = cumulative_population,
        share_rural_population_pct = 100 * cumulative_population/total_rural_population)

    cumulative_reach <- rbind(cumulative_reach, site_reach)
}

15.6 Calculate combined portfolio reach

Individual transferability maps can overlap geographically. To calculate the combined reach of the portfolio, the maximum transferability value across all reference sites is calculated for each pixel.

This creates an envelope representing the best match to at least one reference site.

maximum_transferability <- app(transferability_stack, fun = max, na.rm = TRUE)

plot(maximum_transferability, main = "Maximum transferability across reference sites",
    range = c(0, 1))

The default threshold below is 0.6, as used in the original script. The threshold can be changed depending on the desired level of similarity.

selected_threshold <- 0.6

combined_reach_mask <- ifel(maximum_transferability >= selected_threshold, 1, NA)

combined_cropland <- mask(cropland_area_ha, combined_reach_mask)

15.8 Interpretation and limitations

The transferability maps identify areas whose measured environmental and socioeconomic characteristics resemble those of the reference sites. The cumulative reach curves quantify the cropland area and rural population located within these areas at different transferability thresholds.

Several limitations should be considered when interpreting the results:

  • Indicator selection: transferability depends on the variables included in the analysis. Important unmeasured constraints may affect actual technology performance.
  • Standardization: Z-scores give each indicator a comparable scale, but do not necessarily give each indicator equal agronomic importance.
  • Distance metric: Euclidean distance assumes that differences across indicators contribute additively to overall dissimilarity.
  • Decay parameter: the value of lambda controls the rate at which transferability declines with distance and should be tested for sensitivity.
  • Reference-site representation: site means may conceal within-site heterogeneity.
  • Spatial resolution: resampling datasets to a common grid does not create new information at finer spatial scales.
  • Population estimates: population totals depend on the original raster units, spatial alignment and resampling procedure.
  • Interpretation: environmental similarity is a proxy for potential transferability, not a direct prediction of adoption, yield response or technology performance.

A useful next step is to compare transferability maps and cumulative reach estimates under alternative indicator sets, decay parameters and transferability thresholds.
